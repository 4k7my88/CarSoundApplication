# 길굿

내 차가 치는 장단, 지역마다 달라지는 길 위의 농악.

운전자의 주행(브레이크, 방향지시등, 와이퍼, 주행 모드, 위치)을 실시간으로 꽹과리·징·장구·북 장단으로 바꾸는 차량용 생성 사운드 앱의 **시연용 웹 프로토타입**입니다. 현대자동차그룹 차량용 앱 개발 공모전 출품 기획을 바탕으로 합니다.

## 실행

빌드 없이 `gilgut-demo/index.html`을 Chrome에서 엽니다. 화면을 한 번 클릭한 뒤 ‘자동 시연’을 누르거나, 기어를 D로 옮기고 가속 슬라이더를 올립니다.

- 위쪽: 차량 디스플레이 화면 (주행 중 / 한 판 기록 / 가락 지도)
- 아래쪽: 차량 신호 시뮬레이터 — 각 신호가 대응하는 Pleos Connect SDK 도메인 표기
- `H`: 시뮬레이터 패널 숨김 · ‘화면 녹화’: 탭 화면과 소리를 영상 파일로 저장

## 현재 상태

- 웹 프로토타입이며 Pleos Connect 네이티브 앱(Kotlin)이 아닙니다. 차량 신호는 화면의 시뮬레이터로 대신합니다.
- 악기 소리는 Web Audio 합성음입니다. 정식 버전은 국립국악원 국악기 디지털 음원(공공누리 제1유형)을 사용할 예정입니다.
- 장단과 권역별 가락은 시연용 근사치입니다.
